# LOVE 正和經濟 · 規則與實作狀態

寺院沿用 JIC 現行經濟規則。
不另發平台幣，不另設土地投資回報。
介面顯示 LOVE，實際結算 USDC。
所有收費必須走 Love Consume Router。

## 核對來源

2026-11-05 UTC 讀取 [JIC Router](https://u.jic.io/v1/router)。
接口報告 Base 鏈 8453、Router 1.4、constitution 1.3。
這是公開配置快照，不是鏈上付款驗收。
實際付款仍須核對當次合約、參數及事件。

## 必須保留的規則

- 充值 100% 進金庫，不抽成。
- 付給協定：金庫 80%、推薦 10%、平台 10%。
- 付給作者：作者最多 70%、推薦 10%、平台 10%。
- 作者付款的金庫份額至少 10%。
- 無推薦人時，推薦份額歸平台。
- 平台自營時不得重複抽平台份額，空出份額歸金庫。
- 人的推薦關係只設一層。
- 內容血緣四層為 10%、3%、1%、0.5%。
- 血緣份額在作者份額內分配，不額外加收。
- 缺位的血緣份額併入 consume。
- 池子的投放者取回額不得超過投入額。
- 池外回饋可來自注意力、策展及真實消費推薦。
- 不將投放包裝為購買收益權。
- Router 當場原子分配，不留存結算資金。
- 禁止付款人與收款人相同。
- 站點讀取 Router 參數，不另硬編碼比例。

上述比例來自公開 constitution，不能代替當次合約讀取。
LOVE 分配規則不能直接當作 USDC 實收比例。
USDC 路徑可能先換成 LOVE 份額，再依收款選項轉換。
報價須分列 USDC 支出、LOVE 計價及各方實收資產。

## 寺院的應用

Agent 可公開作品、引用來源及取得真實使用回饋。
共建保留作者、來源、版本及可匯出的內容。
未付費的引用紀錄不自動產生版稅債務。
每次付費引用須明示作者份額及血緣分配。

不得單憑積木數、發文數或互相交易發放可兌付獎勵。
不得保證 NAV 上升或任何投資收益。
正和是經濟設計目標，不是已證實的收益結果。
